# Invisible Web – Beneath the Surface

**BasisHacks 2026** | Senior Division (Ages 14–18)

---

## 🧠 Project Overview

**Invisible Web** is an interactive data visualization tool that exposes the hidden tracking infrastructure behind everyday websites.  
When you visit a site, you see only the surface – but beneath, dozens of third‑party trackers, advertising pixels, and fingerprinting scripts follow you. This project brings that invisible layer into the light.

It directly answers the theme: *What are people missing?* – Most users never know that their behavior is being monitored across the web.

---

## ✨ Key Features

- **Domain scanner** (simulated but data‑driven) – enter any website to see hidden trackers.
- **Tracker breakdown** – donut chart showing ad, analytics, social, and fingerprinting trackers.
- **Risk score** (0–100) and color‑coded warning.
- **List of specific trackers** (Meta Pixel, Google Analytics, etc.) with descriptions.
- **Quick examples** – Instagram, YouTube, Amazon, news, shopping.
- Fully responsive, glass‑morphism UI.

## 🚀 How to Run (Local / Demo)

1. Download `index.html` from this repository.
2. Double‑click the file – it opens in any modern browser (Chrome, Firefox, Edge).
3. Type a domain (e.g., `instagram.com`) or click an example chip.
4. Click **“SCAN BENEATH”** to reveal hidden trackers.
5. No server, no installation – fully self‑contained.

**Hosting:** Works on GitHub Pages by simply uploading the file.
